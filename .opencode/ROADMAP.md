## Phase 1

Project Registry

Goal:

Track repositories known to Dev-Buddy.

Features:

- Project registration
- Project discovery
- SQLite storage
- Project dashboard

Success Criteria:

Dev-Buddy knows every repository the user works on.

---

## Phase 2

Project Memory

Goal:

Create persistent project memory.

Features:

- .devbuddy directory
- project.json
- tasks.json
- decisions.json
- notes.json

Success Criteria:

Project knowledge survives restarts.

---

## Phase 3

Session Tracking

Goal:

Track current work.

Features:

- Active project
- Active branch
- Recent files
- Current task

Success Criteria:

Dev-Buddy knows what the developer is doing.

---

## Phase 4

Resume Briefings

Goal:

Restore context instantly.

Features:

- Session summaries
- Startup briefings
- Unfinished work detection

Success Criteria:

Developer can continue work immediately.

---

## Phase 5

Activity Logging

Goal:

Collect historical activity.

Features:

- File activity
- Tool activity
- Branch activity
- Session activity

Success Criteria:

Historical timeline exists.

---

## Phase 6

Semantic Code Intelligence

Goal:

Understand code semantically.

Features:

- Embeddings
- Semantic search
- Related code discovery

Success Criteria:

Code can be located by meaning.

---

## Phase 7

OpenCode Memory Integration

Goal:

Inject memory into the agent.

Features:

- Project memory retrieval
- Session memory retrieval
- Context injection

Success Criteria:

OpenCode becomes context aware.
