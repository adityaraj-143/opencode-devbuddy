# Dev-Buddy Vision

## Overview

Dev-Buddy is a persistent developer intelligence layer built on top of OpenCode.

OpenCode remains the coding engine.

Dev-Buddy adds long-term memory, workspace awareness, project intelligence, developer intelligence, and context restoration.

The goal is not to compete with OpenCode's coding capabilities.

The goal is to make OpenCode feel like a persistent Jarvis for software development.

---

## Core Mission

Eliminate context rebuilding.

A developer should never need to spend time remembering:

- What they were working on
- Why a decision was made
- Which files mattered
- Which tasks are pending
- What projects need attention

Dev-Buddy should restore that context automatically.

---

## Core Principles

### Local First

All data should remain on the developer's machine.

No cloud dependency should be required.

---

### Persistent Memory

Context should survive:

- Application restarts
- Machine reboots
- Days
- Weeks
- Months

---

### Project Intelligence

Dev-Buddy should understand:

- Repository structure
- Architecture
- Goals
- Tasks
- Decisions

---

### Session Intelligence

Dev-Buddy should understand:

- Current task
- Current branch
- Recent files
- Recent activity

---

### Developer Intelligence

Dev-Buddy should understand:

- Preferences
- Habits
- Work patterns
- Frequently used tools

---

### Workspace Intelligence

Dev-Buddy should understand:

- Open projects
- Browser tabs
- Terminal sessions
- Window layouts

---

### Cross Project Awareness

Dev-Buddy should understand all repositories together.

Not one repository at a time.

---

## Non Goals

Dev-Buddy is NOT trying to:

- Replace OpenCode
- Replace LLMs
- Become another coding agent
- Compete on code generation

OpenCode already solves those problems.

---

## Relationship With OpenCode

OpenCode is the execution engine.

Dev-Buddy is the memory and intelligence layer.

OpenCode handles:

- Agent execution
- Tool calling
- MCP integration
- Model interaction

Dev-Buddy handles:

- Memory
- Context
- Persistence
- Resumption
- Analytics
- Workspace awareness

---

## Long Term Vision

A developer should be able to say:

"Resume what I was doing yesterday."

and Dev-Buddy should know:

- Project
- Branch
- Files
- Tasks
- Decisions
- Workspace

without requiring explanation.

The final goal is a true Jarvis for developers.
